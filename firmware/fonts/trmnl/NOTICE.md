# TRMNL pixel fonts

TRMNL12, TRMNL16 and TRMNL21 (Regular and Bold), from the TRMNL bundle of the
TRMNL Framework (<https://trmnl.com/font-family>), released 2026-09-28.

- Designer: Heavyweight Digital Type Foundry, <https://heavyweight-type.com>
- Copyright © 2026 Heavyweight Digital Type Foundry s.r.o.
- License: SIL Open Font License 1.1 (see `OFL.txt`), which allows embedding
  in software and firmware as long as this notice and the license go with it.

Unmodified TTF files. Each is drawn on a pixel grid of 12, 16 or 21 px per em,
so it renders without grey edges at that size and its integer multiples.
